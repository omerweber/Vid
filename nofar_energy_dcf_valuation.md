## 4. WACC CALCULATION

### 4.1 Cost of Equity (Ke) — CAPM

```
Ke = Rf + β × ERP + CRP

Where:
  Rf  = Risk-Free Rate (Israel 10Y Gov Bond)        = 4.50%
  β   = Levered Beta                                 = 1.25
  ERP = Equity Risk Premium (Israel)                  = 5.50%
  CRP = Country Risk Premium (blended multi-country)  = 1.00%
───────────────────────────────────────────────────────────────────
  Ke  = 4.50% + (1.25 × 5.50%) + 1.00%
  Ke  = 4.50% + 6.875% + 1.00%
  Ke  = 12.38%
```

**Beta Derivation:**

| Input                    | Value  | Source                               |
|--------------------------|--------|--------------------------------------|
| Unlevered Beta (peers)   | 0.55   | Median of Enlight, Energix, OPC      |
| Target D/E               | 1.50x  | Based on management's target leverage |
| Tax Rate                 | 23%    | Israeli corporate tax rate            |
| Levered Beta             | 1.185  | β_L = β_U × [1 + (1-t) × D/E]       |
| **Rounded Levered Beta** | **1.25** | Rounded up for execution/size risk  |

```
β_L = 0.55 × [1 + (1 - 0.23) × 1.50] = 0.55 × [1 + 1.155] = 0.55 × 2.155 = 1.185 ≈ 1.25
```

### 4.2 Cost of Debt (Kd)

```
Pre-Tax Cost of Debt:
  Bond Series Weighted Avg Coupon                     = 5.80%
  + Spread Adjustment (sub-investment-grade premium)  = 0.70%
  ────────────────────────────────────────────────────
  Pre-Tax Kd                                          = 6.50%
  After-Tax Kd = 6.50% × (1 - 0.23)                  = 5.01%
```

## 5. TERMINAL VALUE

### Method 1: Gordon Growth Model (Perpetuity Growth)

```
TV = UFCF_2030 × (1 + g) / (WACC - g)

Where:
  UFCF_2030  = NIS 984M
  g          = 2.5% (long-term perpetuity growth rate)
  WACC       = 8.0%

TV = 984 × (1.025) / (0.08 - 0.025)
TV = 1,008.6 / 0.055
TV = NIS 18,338M

PV of Terminal Value = 18,338 / (1.08)^5
PV of Terminal Value = 18,338 / 1.4693
PV of Terminal Value = NIS 12,481M
```

**Perpetuity Growth Rate Justification (g = 2.5%):**
- Israel long-term inflation target: ~2.0%
- Global electricity demand growth: ~2-3% annually
- Renewable energy capacity growth: 5-8% globally but decelerating
- Chosen rate reflects inflation + modest real growth for a mature renewable portfolio
- Implied terminal EV/EBITDA: 18,338 / 1,770 = 10.4x (reasonable for mature renewables)

### Method 2: Exit Multiple

```
TV = EBITDA_2030 × Exit Multiple

Where:
  EBITDA_2030    = NIS 1,770M
  Exit Multiple  = 10.0x EV/EBITDA (mature renewable energy company)

TV = 1,770 × 10.0
TV = NIS 17,700M

PV of Terminal Value = 17,700 / (1.08)^5
PV of Terminal Value = 17,700 / 1.4693
PV of Terminal Value = NIS 12,046M
```

**Exit Multiple Justification:**
- Current peer Energix trades at ~20x EV/EBITDA (growth premium)
- Environmental services median: ~12.8x
- Mature utility-scale renewable platforms: 8-12x
- 10.0x reflects a de-risked, operational portfolio at steady state
- Cross-check: Implied perpetuity growth at 10.0x = ~2.2% (consistent with Gordon Growth)
